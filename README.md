# BPSR MIDI Lite / Studio

Windows MIDI player for **Blue Protocol: Star Resonance** instruments.

**Website:** https://zudin987.github.io/projects/bpsr-midi/

- **Lite** — local MIDI + Online Sequencer.
- **Studio** — Lite features + experimental YouTube/audio → MIDI.

## Use

1. Download Lite or Studio from [Releases](https://github.com/Zudin987/BPSR-MIDI-Lite/releases/latest).
2. Open the EXE.
3. Choose **Instrument → Category → Song**.
4. Run **Song Check** if you want to check remapped/skipped notes.
5. Press **Play** and return to BPSR before the countdown ends.

Press **F10** at any time to stop playback and release held keys.

No Python install is needed for the release builds. The app does **not** modify BPSR game files.
