# BPSR MIDI Lite v1.0.0

First public-ready release by **MrEz**.

## Highlights

- Keyboard, Guitar, and Bass support
- Safe unlock profiles for each instrument
- Fixed profiles avoid `<` and `>` page switching
- Automatic MIDI preview and remapping
- MIDI library with Open Folder and Reload
- Windows light/dark theme support
- Standalone Windows EXE; users do not install Python
- F10 emergency stop and multiple input methods

## MIDI selection advice

Prefer simple piano, melody, acoustic, or solo-instrument MIDI files. Dense orchestral, full-band, drum-heavy, and multi-instrument arrangements may sound crowded or unusual after being fitted to the game's available notes and chord limits.

## Download

Normal users should download `BPSR-MIDI-Lite.exe` directly from the Release assets and run it. No ZIP extraction or Python installation is required.
