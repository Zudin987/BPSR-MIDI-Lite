# BPSR MIDI Lite v3.1.1

Small smoothness update for the v3.1 single-window player.

- Live MIDI visualizer is now capped at **30 FPS** (about one frame every 33 ms), up from the previous 80 ms refresh.
- Active-key and visualizer activity indicators refresh with the same 30 FPS render loop.
- Playback timing, MIDI planning, BPSR key output, note mapping, pause/resume, Local/Online search, and safety rules are unchanged.
- **BPSR MIDI Studio 0.2.1 Experimental Beta** is rebuilt with the same 30 FPS visualizer and remains available as an additional asset on this release.
