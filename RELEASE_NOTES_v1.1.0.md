# BPSR MIDI Lite v1.1.0

This update focuses on safer startup, easier song selection, and better tester feedback.

## What changed

- The EXE now opens normally without an automatic Administrator prompt.
- **Restart as Administrator** is available inside the app when BPSR does not receive input.
- Every selected MIDI receives a **Good fit**, **Busy**, or **Very complex** rating.
- The preview explains why a song may sound crowded.
- **Copy diagnostics** creates a ready-to-paste report for testing and bug reports.

## Recommended testing

1. Run the app normally and test input in Notepad.
2. Test Keyboard, Guitar, and Bass in BPSR.
3. Only use Restart as Administrator when Notepad works but BPSR does not.
4. Compare Good fit, Busy, and Very complex songs to confirm that the guidance feels reasonable.
5. Copy diagnostics after any error and include the report when submitting feedback.

Requirements: Windows 10/11 64-bit.
